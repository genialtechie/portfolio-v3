## How I work

- **Measure before optimizing.** This site's scene went from 25 MB to 12.7 MB because I inspected the file first instead of guessing ([how](#page=writing/scene-diet)).
- **Make the failure path good.** At ReviewTailor, validation and recovery paths took failed generations from about 20% to under 4%. Payments get idempotency, and loading gets an honest progress bar.
- **Enforce rules with the system, not memory.** A migration that fails when a table is missing row-level security beats a checklist.
- **Use AI as leverage, and own the result.** I use coding agents heavily. The architecture, the trade-offs and the bugs I sign off on are mine.
