## How I work

- **I measure before I optimize.** This site's 3D scene went from 25 MB to 12.7 MB because I looked at what was actually in the file first ([here's how](#page=writing/scene-diet)).
- **I plan for things going wrong.** At ReviewTailor, adding validation and recovery paths took failed generations from about 20% to under 4%. Payments get idempotency, and loading screens show real progress.
- **I let the system enforce the rules.** For example, a database migration that fails if a table is missing security rules, so nobody has to remember to check.
- **I use AI a lot, and I own the result.** I use coding agents every day. The architecture, the trade-offs and the bugs are still on me.
